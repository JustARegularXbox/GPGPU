General Purpose GPU

How GPUs turned into what we know of them today

Few big cores, or thousands of small ones

CPU

Sure, CPUs these days can go up to 96 cores. It's still not even comparable.

GPU

Not really to scale. A GPU, especially these days, would have many more cores. This is just a representation.

Same instruction, different data

How can you take a single instruction and put multiple data through it? That does't make sense. And it's true. But what the GPU takes advantage of is its parallelism. You're able to take a single instruction, feed multiple pieces of data to the hundreds to thousands of cores, and ask them to perform the same operation on all of them. Think of a 128x128 matrix and all of a sudden it starts making sense why SIMD was so important in the world of games.

Talking to the GPU

CUDA

Proprietary Application Programming Interface (API) from Nvidia that has a software side, which allows you to take control of both the CPU and GPU as needed, as well as a library of other APIs (prefixed with cu from CUDA, take for example cuDNN or cuBLAS) in order to perform parallel operations.

OpenCL

Free and open source API first developed by Apple in order to get parallel computing out of a proprietary format and into a specification, that GPU vendors would be then able to implement into their drivers. Just like CUDA preceeding it, it allows for programming of both the CPU and the GPU (as well as DSPs and FPGAs).

Vulkan Compute

In 2016, the people behind OpenGL and OpenCL released Vulkan. A fully open source, homogenous API that allowed for both graphics as well as general compute. Its biggest advantage is that as long as a driver implements the Vulkan specification, it's allowed to do anything that the spec allows. Including composble kernels.

WebGPU

The modern departure from state machines on browsers. It implements a command queue, and with that it allows the use of general purpose GPU software by means of a browser. Just like Vulkan before it, it compiles to Standard Portable Intermediate Representation, allowing the use of a single program on multiple devices.
