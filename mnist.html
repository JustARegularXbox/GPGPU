What is MNIST?

MNIST (Modified National Institute of Standards and Technology) are 70,000 standardized handwritten digits of resolution 28×28 in grayscale where 60k of those are used to train the model with the remainder 10k being used for testing. It was first theorized in the paper LeCun et al. from 1998

What one inference is

Inference is a totality of forward passes that computes the output layer. The way it works is that there's something that transforms the input into numbers, more specifically into a matrix representation. Then for every layer N+1 following the input layer, (being denoted with N) we perform a matrix multiply. The manner in which we perform it is that we take the bias of each N+1's and add it to the result of the matrix multiply indexed i (where 0 < i < N) operation. We then take the ReLU (Rectified Linear Unit) of the aforementioned matmul + bias in order to create a normal distribution of values. Then, last but not least, we take the softmax of all of that (again, on a per layer basis) at every step in order to neutralize any and all values that are below a certain threshold. After you've repeated this step i (with 0 < i < N) times you've finished with the first forward pass.

Weight
The relation which connects two activation states between one another.
Bias
The affinity with which a certain activation gets triggered by a certain weight based on the input layer.
Activation
The value of one element in one of the representation matrices.
ReLU
Computes a distribution of the last layer activation and makes it normal.
Softmax
Cuts everything that is below a certain threshold by means of setting them to 0.

Training vs inference

Now take what I've just described for the entirety of fthe inference step. And do it backwards in a way that makes sense. Say you start at the output layer. And you have already fed the input layer. You get a result that's most likely than not what you wanted. So you change the output layer's values to match what you wanted to get with that input. Then you commence backwards propagation. But first you compute the loss function. What it does is it takes the output layer you want and subtracts the result that you actually got. After which you compute the gradient of the change that the layer N-1 (where N is the output layer) has to change by multivariable integrating the entire value, which you then once again softmax in order to try and neuter all of the unnecessary values that don't contribute to the learning process.
